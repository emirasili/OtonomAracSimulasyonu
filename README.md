# OtonomAracSimulasyonu
SAU Yapay Zekaya Giriş Ödevi kapsamında oluşturulmuştur.

🚗 Otonom Araç Simülasyonu Projesi

Bu proje, bir aracın şehir içi ortamda engellerden kaçınarak, trafik ışıklarına uyarak ve en uygun rotayı bularak hedef konuma ulaşmasını sağlayan bir simülasyon geliştirmeyi amaçlar.
